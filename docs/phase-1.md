# Phase 1 — Setup Checklist

- [ ] Install/verify Python 3.12
- [ ] Install/verify Git
- [ ] Install/verify VS Code
- [ ] Create local virtual environment
- [ ] Activate virtual environment
- [ ] Upgrade pip
- [ ] Install only initial development dependencies

## Phase 1 definition of done

The repository exists, the Python environment activates successfully, the backend smoke test runs, Git tracks the project, and no secrets or virtual-environment files are committed.
